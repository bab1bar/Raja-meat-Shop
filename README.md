#  🍗Raja-meat-Shop
meat to eat. everything in one shop . 



A modern, mobile-first Progressive Web App (PWA) for a chicken and meat shop.
Customers can browse products, check prices, place orders, and contact the shop through WhatsApp.

## 🚀 Features

### Customer Features
- Browse chicken and meat products
- View price per kg / half kg etc 
- Select cutting options (whole, cut) 
- Add items to cart
- Calculate total price
- WhatsApp ordering system(currently frontend temporarily) 
- Mobile-friendly design
- Installable as PWA(like a normal app) 
- Works offline(some features) 

### Business Features
- Retail and wholesale customer modes
- Restaurant bulk orders
- Customer order history(coming soon )
- Special offers and deals
- Inventory availability

### Admin Features (Coming Soon)
- Update daily prices
- Add/remove products
- Manage stock
- View orders
- Print receipts
- Customer management


## 🛠️ Technologies Used

Frontend:
- HTML5
- CSS3
- JavaScript (ES6+)
- Progressive Web App (PWA)
- Service Worker
- Web Manifest

Backend (Planned, coming soon):
- Node.js
- Express.js
- MySQL/PostgreSQL
- REST API
- JWT Authentication
